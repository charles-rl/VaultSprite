This is a tiny desktop mascot that'll run around and cause mischief.

The original program can be found here - http://www.group-finity.com/Shimeji/

You can make your own by replacing the image files in the img folder with your own sprites.

This one is a kitty shimeji based on one of my cats named Dieter. His conf files have been slightly altered and he has a few extra frames.

-Separate running animation
-Slightly lengthened tail chasing animation
-Idle tail waving animation while standing/sitting
-Extra frame while falling
-Hanging frame


A few notes:

-Right click on him and select "baibai" to get rid of one of them.

-Right click the icon in the taskbar to bring up a menu. The commands go:

--Spawn new Dieter
--Come here!
--Get rid of all but one
--Bring back IE Windows (Sometimes he'll throw your browser windows around)

--Exit

He'll only climb and throw around browser windows and MSN windows, I think.
